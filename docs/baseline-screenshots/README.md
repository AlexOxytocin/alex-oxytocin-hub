# GOD-2 visual baseline

Captured from production on 2026-08-23 with headless Chrome. These images record the fragmented pre-migration site and are comparison evidence, not the target design.

Browser settings: reduced motion, hidden scrollbars, fixed viewport, viewport-only capture after a 2.5-second virtual-time budget. No authenticated or mutating interaction was performed.
