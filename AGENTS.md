# MySite: рабочие инструкции Codex

## Базовый принцип

Это публичный Astro-сайт одного владельца. Выбирай минимальное изменение и
проверку, соответствующую затронутому риску. Сохраняй незакоммиченные изменения
пользователя и не смешивай их с текущей задачей.

## Уровни работы

- `local` — анализ, прототип, текстовая или небольшая локальная правка. Нужна
  только проверка затронутого результата.
- `tracked` — значимый баг, функция, изменение контента, маршрута, layout или
  процесса. Используй существующую задачу Jira `GOD` либо создай одну при её
  отсутствии; зафиксируй критерии, проверку и короткий итог.
- `release` — deployment, Nginx/DNS, permanent redirects, security, удаление
  server assets или другая production-операция. Используй соответствующий
  runbook, staging/public verification и rollback boundary.

Наличие Jira-задачи само по себе не требует отдельной ветки, commit, push, PR,
полного test suite, независимого review или deployment. Не выполняй эти Git и
внешние действия без прямого запроса или явного release-плана.

## Проверки

- Текст/данные: ближайшая schema/content/link-проверка.
- Компонент или layout: затронутые viewport и browser checks.
- Routing, SEO, downloads или backend contract: соответствующий contract test.
- Полный `npm test`, RU/EN visual matrix и все release verifiers: перед release
  либо когда изменение действительно пересекает эти границы.

Правила `.ai-style-rules.md` сохраняют дизайн и задают release acceptance. Они
не превращают каждую локальную правку текста или данных в полный release gate.

## Граница Community Mini App

Telegram bot, Mini App, API и PostgreSQL развиваются в репозитории
`C:\Users\User\community_bot`. Этот репозиторий может содержать публичное
описание, ссылку или routing домена приложения, но не владеет его runtime-кодом
и development workflow.

## Готовность

Локальный build или тест — локальный результат. Говорить, что публичное
изменение готово, можно только после deployment и проверки фактического
публичного URL. Субагенты используются только по прямому запросу пользователя.
